# Milorad Dakic — Portfolio

A lightweight, responsive portfolio for Java Backend Developer Milorad Dakic.

## Preview

Open `index.html` directly in a browser, or start a local static server from this folder:

```powershell
py -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a public repository named `milorad26.github.io` under the `milorad26` GitHub account.
2. Push the contents of this folder to the repository's `main` branch.
3. In repository **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, and save.
4. The site will be available at `https://milorad26.github.io` after Pages finishes deploying.

The site uses plain HTML and CSS; there is no build step or package installation.

## Updating the CV

Replace `assets/Milorad_Dakic_CV.pdf` with the updated PDF, keeping the same filename. Update the experience and skills text in `index.html` as needed.
